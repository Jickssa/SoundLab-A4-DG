# Code of Conduct

## Our standards

SoundLab welcomes constructive participation from people with different levels of experience and backgrounds.

Participants are expected to:
- communicate respectfully and focus criticism on ideas and implementation;
- provide accurate, reproducible technical reports;
- distinguish verified facts from assumptions;
- acknowledge limitations and correct mistakes;
- protect personal information, copyrighted material and private device dumps.

Unacceptable behaviour includes harassment, threats, discriminatory language, deliberate disclosure of private information, impersonation and sustained disruptive conduct.

## Scope

This code applies to repository issues, pull requests, reviews, discussions and other project spaces when someone is representing the project.

## Reporting

Report abusive or unsafe behaviour privately to the repository owner through GitHub. Do not include personal data or sensitive device information in a public issue.

Project maintainers may edit, reject or close contributions that violate this code. Enforcement decisions should be proportionate to the behaviour and focused on keeping collaboration useful and safe.

## Attribution

This policy is adapted from the Contributor Covenant principles. It is a project-specific statement; no external enforcement organization is implied.
