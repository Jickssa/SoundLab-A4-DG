# Help improve SoundLab

Useful feedback is concrete and reproducible. Include device (Analog Four MKI / Analog Keys or Digitone MK1), instrument OS if known, OS/browser, file format and size, and exact steps.

## Feedback areas
1. **Formats**: AFSND/DNSND variants, manifest fields, names/tags and valid archives rejected.
2. **Audition**: audio decode, latency, sequential playback, audio-interface capture and linking a real take to a patch.
3. **MIDI/SysEx**: ports, incomplete messages, routing and errors. State whether the physical device confirmed receipt; browser queueing is not confirmation.

Never publish commercial sound banks, firmware, private dumps, serial numbers or personal data. Use issue templates. Protocol proposals need evidence and a safe test plan.
