# Aidez à améliorer SoundLab

Les retours les plus utiles sont concrets et reproductibles. Indiquez le modèle (Analog Four MKI / Analog Keys ou Digitone MK1), la version OS de la machine si connue, le système, le navigateur, le format/taille du fichier et les étapes.

## Retours recherchés
1. **Formats** : variantes AFSND/DNSND, manifestes, noms/tags et archives rejetées.
2. **Écoute** : décodage audio, latence, lecture séquentielle, capture via interface, liaison d'une prise réelle à un patch.
3. **MIDI/SysEx** : ports, messages incomplets, routage et erreurs. Préciser si la machine physique a confirmé la réception ; la mise en file navigateur n'est pas une confirmation.

Ne publiez jamais de banques commerciales, firmwares, dumps privés, numéros de série ou données personnelles. Utilisez les modèles d'issues. Les propositions de protocole doivent être documentées et accompagnées d'un plan de test sans risque.
